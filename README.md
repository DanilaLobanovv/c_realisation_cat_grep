# Реализация cat и grep на C

Две консольные утилиты для работы с текстовыми файлами: `cat` выводит содержимое файлов, а `grep` ищет строки по базовым регулярным выражениям POSIX. Проект реализует часть возможностей одноимённых системных команд.

## Требования

- компилятор C с поддержкой C11 (по умолчанию `gcc`);
- `make` и POSIX-библиотека регулярных выражений.

## Сборка

Из корня проекта:

```sh
make -C src
```

Исполняемые файлы появятся по путям `src/cat/cat` и `src/grep/grep`. Отдельную утилиту можно собрать командой `make -C src/cat` или `make -C src/grep`. Для очистки используйте `make -C src clean`, для пересборки — `make -C src rebuild`.

## Использование

```sh
./src/cat/cat -n file.txt
./src/cat/cat file1.txt file2.txt
./src/grep/grep -in 'error' file.txt
./src/grep/grep -e 'error' -e 'warning' file.txt
printf 'one\ntwo\n' | ./src/grep/grep 'two'
```

Если файлы не указаны, обе утилиты читают стандартный ввод; `-` в списке файлов также обозначает стандартный ввод.

### Параметры cat

| Параметр | Действие |
| --- | --- |
| `-b`, `--number-nonblank` | Нумеровать непустые строки; имеет приоритет над `-n`. |
| `-n`, `--number` | Нумеровать все строки. |
| `-s`, `--squeeze-blank` | Сжимать последовательности пустых строк. |
| `-e` | Показывать концы строк как `$` и непечатаемые символы. |
| `-t` | Показывать табуляции как `^I` и непечатаемые символы. |
| `-v` | Показывать непечатаемые символы. |
| `-E` | Показывать концы строк как `$`. |
| `-T` | Показывать табуляции как `^I`. |

### Параметры grep

| Параметр | Действие |
| --- | --- |
| `-e шаблон` | Задать шаблон; ключ можно повторять. |
| `-i` | Игнорировать регистр. |
| `-v` | Выбирать строки без совпадения. |
| `-c` | Выводить количество выбранных строк. |
| `-l` | Выводить имена файлов с совпадениями. |
| `-n` | Выводить номера строк. |

Код завершения `grep`: `0` — найдены выбранные строки, `1` — не найдены, `2` — ошибка.

## Тестирование

```sh
make -C src test
```

Интеграционный скрипт сравнивает вывод и коды завершения с системными утилитами. Для полного набора нужны BusyBox (`busybox cat`), GNU `cat` в `PATH`, системный `grep` и стандартные `sh`, `cmp` и `diff`. Тесты отдельных утилит запускаются через `make -C src/cat test` и `make -C src/grep test`.

## Структура

- `src/cat/` — реализация и Makefile утилиты `cat`;
- `src/grep/` — реализация и Makefile утилиты `grep`;
- `src/common/` — общие функции открытия и закрытия входных потоков;
- `src/tests/` — интеграционные тесты.
